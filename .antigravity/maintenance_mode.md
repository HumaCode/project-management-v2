# Maintenance Mode Module (Dynamic & Database Driven)

Implementasi sistem penguncian aplikasi global yang dikelola melalui Admin Panel dengan fitur hitung mundur dinamis.

## 🛠️ Detail Implementasi

### 1. Database Persistence (`settings` table)
Menyimpan konfigurasi maintenance dalam grup `maintenance`:
- `maintenance_mode`: Status aktif ('1') atau non-aktif ('0').
- `maintenance_message`: Pesan kustom yang ditampilkan ke user.
- `maintenance_end_time`: Timestamp estimasi penyelesaian (format: Y-m-d H:i).

### 2. Middleware Control (`CheckMaintenanceMode`)
- **Lokasi**: `app/Http/Middleware/CheckMaintenanceMode.php`
- **Logika**: 
  - Mengecek status `maintenance_mode` di database.
  - Jika aktif ('1'), melempar `Abort(503)` atau menampilkan view maintenance kustom.
  - **Security Hardening**: Jika user (non-dev) sedang dalam kondisi login saat maintenance diaktifkan, middleware akan otomatis melakukan `Auth::logout()` dan `Session::invalidate()` sebelum menampilkan halaman maintenance. Hal ini mencegah adanya sesi "menggantung" selama pemeliharaan.
  - **Bypass**: User dengan role `dev` tetap bisa mengakses aplikasi untuk keperluan debugging/update.
- **Registrasi**: Didaftarkan di grup middleware `web` di `bootstrap/app.php` agar memiliki akses ke sesi dan autentikasi user.

### 3. UI/UX (Premium Design)
- **View**: `resources/views/errors/maintenance.blade.php`
- **Estetika**: Mengadopsi desain 403 (Glassmorphism, Neon Orange theme, Scanline animation, Corner decorations).
- **Fitur Baru**:
  - **Centered Message**: Pesan admin ditampilkan besar di tengah.
  - **Real-time Countdown**: Menggunakan JavaScript untuk hitung mundur (Hari : Jam : Menit : Detik) yang berdetak setiap detik.
  - **Auto-Finish State**: Menampilkan teks konfirmasi jika waktu pemeliharaan telah habis.

### 4. Admin Panel Integration
- **Controller**: `SettingController@updateMaintenance`
- **Frontend**: 
  - **Flatpickr**: Digunakan untuk pemilihan tanggal dan waktu yang presisi.
  - **AJAX Saving**: Data disimpan tanpa refresh halaman dengan validasi state checkbox.
  - **JavaScript**: `public/assets/auth/backend/js/setting.js` menangani inisialisasi dan pengiriman data.

## 🚀 Cara Penggunaan
1. Masuk ke **Pengaturan Website** > **Backup & Maintenance**.
2. Masukkan pesan dan pilih estimasi waktu selesai menggunakan picker.
3. Aktifkan toggle dan klik **Simpan**.
4. Seluruh akses user (kecuali Developer) akan dialihkan ke halaman maintenance.
